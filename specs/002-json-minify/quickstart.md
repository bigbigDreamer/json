# Quickstart: JSON 一键压缩

## 目标

验证 JSON 一键压缩功能在当前 Aura JSON Studio 中满足规格、设计和契约要求。

## 准备

1. 在仓库根目录安装依赖。
2. 启动本地开发环境。
3. 打开首页工作台。

## 手工验证流程

### 场景 1: 标准多行 JSON 压缩成功

1. 在输入区粘贴一段带缩进和换行的合法 JSON。
2. 触发“压缩 JSON”操作。
3. 确认界面展示压缩结果状态。
4. 执行复制。
5. 将复制内容粘贴到任意文本区，确认是一行紧凑 JSON，且语义与原输入一致。

### 场景 2: 已压缩 JSON 再次压缩

1. 输入一段本来就是单行的合法 JSON。
2. 触发压缩。
3. 确认操作成功，结果内容稳定，没有多余改写。

### 场景 3: 顶层基础类型

1. 分别输入 `null`、`true`、`123`、`"hello"`。
2. 对每个样本触发压缩。
3. 确认都能得到合法结果，而不是被错误拒绝。

### 场景 4: 隐形字符清理后压缩

1. 加载或粘贴包含 BOM、零宽空格等字符的样本。
2. 触发压缩。
3. 确认结果成功生成，并能看到清理摘要。

### 场景 5: 非法 JSON 失败提示

1. 输入包含尾随逗号或缺失引号的非法 JSON。
2. 触发压缩。
3. 确认界面不生成新压缩结果，并显示可理解的失败原因。
